🌐 Projeto Web

Projeto desenvolvido para colocar em prática conceitos de desenvolvimento web, utilizando HTML, CSS e JavaScript.

A proposta foi criar um site com diferentes páginas e elementos interativos, trabalhando estrutura, estilização, responsividade e funcionalidades básicas com JavaScript.

🛠️ Tecnologias utilizadas
HTML5 — estrutura e organização das páginas
CSS3 — estilização, layout e responsividade
JavaScript — interações e funcionalidades
🎯 Objetivo

O principal objetivo do projeto foi entender na prática como funciona o desenvolvimento de uma aplicação web, desde a criação da estrutura com HTML até a estilização com CSS e a implementação de funcionalidades utilizando JavaScript.

Além do resultado final, o projeto serviu como uma oportunidade para estudar e compreender melhor a organização do código e a relação entre as diferentes tecnologias utilizadas.

🤖 Uso de Inteligência Artificial

Durante o desenvolvimento, utilizei Inteligência Artificial como ferramenta de apoio ao aprendizado.

Como ainda não possuo domínio completo de HTML, CSS e JavaScript, utilizei a IA para auxiliar na criação e correção de partes do código. Porém, o foco não foi apenas obter o código pronto: procurei analisar como cada parte funcionava, entender a lógica utilizada e observar o impacto das alterações no projeto.

Dessa forma, o projeto também funcionou como uma forma de aprendizado, permitindo conhecer recursos e estruturas que ainda estou estudando.
